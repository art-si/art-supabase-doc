# TMS 智慧运输

TMS 覆盖运输主数据、开单、运单执行、配载、在途监控、签收回单和结算协作。推荐先建立可靠主数据，再进入订单与运单流程。

## 上线前准备

1. 维护客户、客户地址和常用线路。
2. 维护承运商、司机、车辆引用和站点。
3. 建立货物、合同、客户价格与承运商价格。
4. 为开单、配载、发车、签收、费用和 AI 分析分别配置按钮权限。
5. 需要地图时配置高德地图浏览器 Key、安全码和允许域名。

## 标准业务流程

```text
客户委托
  → 开单 / AI 识别
  → 生成原始运输单
  → 待运载：普通配载 / 合单 / 拆单
  → 生成调度执行运单并分配车辆、司机
  → 已配载 / 发车
  → 在途监控与异常处置
  → 到达、签收、回单
  → 费用、对账、收付款与利润
```

## 智能开单

在“开单”页面选择客户、起讫地、货物、时间和运输要求。已有合同与价格时优先引用主数据，避免在订单中重复录入不可治理的文本。客户未明确选择“允许合单”时，原始单默认禁止合单。

AI 智能填单可以识别文本或图片，但只生成建议和回填表单。保存前确认：

- 客户与地址是否匹配当前租户。
- 收发货联系人、电话和时间是否准确。
- 重量、体积、件数及单位是否一致。
- 是否需要拆分多个运单。
- 客户价格、承运商价格和附加费用是否符合合同。

## 运单与配载

“待运载运单”列出仍有未调度货量的原始运输单；“已配载运单”列出调度生成的执行运单。每张执行运单都有独立运单号，来源明细保存在 `tms_waybill_order_allocation`。原始运输单的客户、货物和收发要求在首次调度后保持不变，详情可反查全部执行运单。

- 普通配载：一张原始单生成一张执行运单。
- 合单：客户逐单明确允许、线路与时间窗口匹配、货物兼容且收货地址相近时，多张原始单生成一张执行运单，共用一车一号；各原始单保留独立货量、费用和签收记录。合单执行运单不能再次拆分。
- 拆单：按件数、重量、体积或货物行分配，首次至少生成两张执行运单；每批可安排不同车辆、时间和收货地址。未分配货量仍留在待运载列表，原始单显示部分调度，可继续添加单个或多个批次。所有有效执行运单的分配量不能超过原始货物行总量。

服务端会再次检查按钮权限、租户、车辆与司机资质、核载吨位和容积、货物余额，以及合单许可与兼容条件。运费按原始单货物行重量分摊；总重量为零时依次按体积、件数分摊。末批吸收分位舍入差额，确保各执行批次分摊金额合计等于原始单运费。

## 在途监控

在同一驾驶舱查看运输进度、车辆位置、报警、司机与货物信息。地图异常时先区分“定位数据未上报”和“地图配置错误”。

![TMS 实时在途监控](/screenshots/in-transit.png)

AI 异常研判用于汇总信号和提出处置建议，真正的工单、通知、改派或状态变化仍由有权限的操作人员确认。

## 签收与回单

到达后按执行运单登记签收时间、签收人和回单附件，并逐张原始单记录实收件数、异常件数及说明。合单的破损只归属对应原始单；拆单的原始单在各批次全部签收前保持部分签收。需要更正时可复核签收，系统追加审计事件。OCR 可以辅助识别回单，但需人工复核单号、签字、日期和异常说明。

客户对账以原始运输单为单位，一张原始单只计一次原始运费；同车合单的不同客户仍各有独立对账项。只有原始单全部签收后才进入客户对账候选。承运商对账按调度执行运单归集已审核的运单成本，执行单分摊运费在待对账费用选择时作为只读对照；它不会自动变成承运商应付，以免把客户应收和承运成本混为一笔。

## 司机端协同

独立的 [TMS 司机端](/modules/driver) 支持 H5 与微信小程序。调度将运单分配给司机后，司机可在移动端接受任务，完成装卸货定位打卡、发车、到达、签收、收车、现场凭证和费用上报。

Web 管理端与司机端共享同一条服务端运单状态机。若两端显示不一致，先检查司机分配、状态同步、服务端事件和当前会话，不要通过直接修改数据库状态绕过业务节点。

## 价格与结算

客户价格与承运商价格应分别维护，并保留适用线路、货物、计价单位和生效时间。历史交易需要快照的价格或名称可以保留快照字段；普通主数据名称不要重复拷贝到业务表。

## 常见问题

| 问题                | 检查                                           |
| ------------------- | ---------------------------------------------- |
| 开单找不到客户/地址 | 主数据状态、租户、地址归属与角色读取权限       |
| 运单无法配载        | 运单状态、车辆/司机状态、按钮权限与服务端校验  |
| 地图没有位置        | 地图 Key、安全码、允许域名、定位上报和坐标格式 |
| 签收后财务无数据    | 运单状态、费用生成、结算契约和回调是否成功     |
| AI 字段匹配错误     | 原文质量、主数据重复、Prompt 版本与用户反馈    |
