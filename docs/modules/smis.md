# SMIS 安全生产

SMIS 当前已经完成从空壳到业务应用的重建，覆盖安全基础资料、设备设施、人员资质培训、应急救援、反违章、劳动防护、工器具和事故管理，并持续补齐跨流程联动与统计能力。

## 上线前准备

1. 建立场所、供应商、检查分类和法定节假日等公共资料。
2. 按组织岗位维护风险清单、安全生产责任与岗位作业指导。
3. 建立设备分类、存放位置、物资分类、工种工项和证书类型。
4. 配置查看、新增、编辑、提交、审核、发布、领用等精确按钮权限。
5. 以测试租户完成一轮培训、演练、领用与事故处置流程，确认 RLS 和跨组织范围。

| 设备设施     | 设备分类、存放位置、设备台账、设备折旧、报检、特种设备台账与分析         |

## 推荐管理闭环

```text
风险 / 标准 / 设备 / 资质基础
  → 计划与任务
  → 培训 / 检查 / 演练 / 领用
  → 违章 / 隐患 / 事故发现
  → 上报、处置、调查与整改
  → 复核、归档与统计分析
```

### 应急预案与演练

先维护危险源和有效应急预案，再编制演练计划。演练记录应引用计划并保留实际时间、参与范围、过程、问题和附件；演练报告汇总结果、改进项和责任闭环。一个预案可以按周期编制多次演练计划，不能用新计划覆盖历史记录。

### 资质与培训

课程、题库、考试和培训记录共同形成学习证据。证书台账应记录持证人员、证书类别、证书编号、有效期、准操项目和附件；临期、过期或准操范围不匹配时，业务流程应明确提示或拦截。

### 劳保用品与工器具

个人配置标准和发放标准用于确定可领物资、周期和数量。申领、审批、发放、归还和库存变化应形成同一条可追溯记录，不能通过直接修改库存绕开业务单据。

### 事故与反违章

事故快报用于第一时间留痕，后续工伤申报、调查、责任、整改和统计应关联同一事件。违章记录应引用分类和标准库，三级教育、公告与历史案例用于复盘和预防。

## 权限与安全

- 普通用户只能读取当前租户与授权组织范围内的安全业务数据。
- 新增、修改、审核、发布、领用、归还和状态变化必须同时经过 UI 与服务端授权。
- 人员选项应通过 HR 最小字段契约获取，不跨模块读取无关敏感信息。
- SMIS 记录用于形成管理闭环，不替代法定检验、专业安全判断或监管要求。

## 常见问题

| 问题             | 检查                                           |
| ---------------- | ---------------------------------------------- |
| 找不到岗位或人员 | 当前租户、组织范围、在职状态与 HR 安全读取契约 |
| 无法新增演练计划 | 应急预案状态、计划编号规则、时间范围与按钮权限 |
| 证书不能用于作业 | 有效期、工种工项、持证人员状态与准操范围       |
| 申领数量异常     | 个人标准、发放周期、历史领用、库存和审批状态   |
| 事故统计不一致   | 快报、调查、工伤申报的关联关系、状态与统计期间 |
