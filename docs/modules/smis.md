# SMIS 安全生产

SMIS 面向安全生产驾驶舱、风险分级管控、隐患排查治理、事故应急、安全培训、设备与特种作业、劳动防护和资质台账。

## 核心闭环

```text
风险辨识与评估
  → 风险分级和管控措施
  → 巡查 / 检查 / 隐患上报
  → 整改责任、期限与证据
  → 复查销项
  → 统计分析与持续改进
```

## 风险与隐患

风险辨识维护风险点、危害因素、评估标准和管控措施。隐患排查计划生成任务，检查人员记录问题、等级、位置和证据，再指定整改责任人与期限。只有复查通过才完成销项。

风险四色图用于表达等级分布，颜色必须配合风险名称或等级文字，不能只靠颜色判断。

## 事故与应急

伤亡事故快报强调及时、准确和最小必要信息；后续事故记录补充原因、责任、损失、处理和整改。应急预案演练计划、记录和报表用于验证预案可执行性，不应把“已演练”等同于“无风险”。

## 培训、资质与特种作业

课程、题库、计划、记录和统计形成培训闭环。特种设备人员证、安全管理人员证、注册安全工程师和特种作业操作证应设置有效期提醒。

动火、高处、受限空间、吊装、临时用电、断路、盲板抽堵等特殊作业申请必须按业务规则审批，并保留作业前条件、监护、措施与完成记录。

## 设备、工器具与防护用品

设备台账、检验、折旧、工器具和防护用品记录要保持领用、归还、检验和个人标准一致。与 HR/VMS 的人员、车辆数据通过平台稳定契约读取，SMIS 不直接引用其他业务仓源码。

## 权限建议

- 隐患上报可以面向更广泛普通用户开放。
- 整改、复查、事故确认和特殊作业审批分开授权。
- 驾驶舱和统计按租户、组织或责任范围裁剪。
- 事故、工伤、证件等敏感字段设置字段权限和最小返回投影。

## 常见问题

| 问题             | 检查                                          |
| ---------------- | --------------------------------------------- |
| 隐患无法销项     | 整改证据、复查状态、责任人和精确按钮权限      |
| 特殊作业无法提交 | 前置措施、证照有效性、审批流程和记录状态      |
| 提醒不准确       | 有效期、时区、状态和定时任务                  |
| 驾驶舱统计不一致 | 指标口径、时间范围、组织范围和已删除/停用记录 |
