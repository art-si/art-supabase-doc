# MDM 主数据治理

MDM 连接跨业务域主数据治理与生产基础配置：统一查看 Platform、HR、TMS、VMS、SMIS 等来源中的关键主档，同时维护生产部门、人员、工厂日历、标准作业、工作中心与工艺路线，为 MES 和 WMS 等执行应用提供稳定身份与规则。

## 物料编码规则

物料档案新增时，服务端在同一事务内按启用规则分配流水号并生成唯一编码；前端预览与服务端使用同一拼接顺序，避免并发建档时重复取号。

- 按物料类型编码：读取物料类型的“编码前缀”，按总长在固定字符前补 `0`，再追加固定字符和 4 位流水号。例如前缀 `R` 生成 `R00-0001`，前缀 `C` 生成 `C00-0001`。
- 按物料分类编码：读取物料分类的“编码前缀”，按总长在固定字符前补 `0`，再追加固定字符和 4 位流水号。例如前缀 `R101` 生成 `R1010-0001`，前缀 `C03` 生成 `C0300-0001`。
- 当前两套标准方案分别使用总长 8 位与 10 位，固定字符均为 `-`。规则缺少业务前缀、编码超长或流水号溢出时，服务端拒绝生成并返回业务提示。

物料编码列表和详情中的“物料描述”按所属分类的描述字段顺序、分隔符和属性组值生成，与编辑弹窗显示一致；分类配置不可用时显示记录已保存的描述。2026-10-02 使用 `B00-0037` 的实际字段配置核对了生成结果，并通过浏览器列表用例验证旧描述不会覆盖展示值。

## 统一治理目录

统一目录按业务语义组织来源主档，而不是简单按数据库表名罗列。

单据类型和业务类型的“所属菜单功能”可按平台菜单层级多选。单据类型保留首选菜单作为旧接口的 `menu_id`，同时把完整范围存入 `menu_ids`；业务类型的菜单范围必须包含在所属单据类型内。业务类型另有“出入库标志”，取值为入库、出库或库存转移，新增时默认入库。服务端校验菜单归属、同一功能内的默认类型唯一性，以及变更单据类型菜单时下属业务类型的有效性。

2026-10-02 变更前的数据与原有函数定义备份在私有表 `app_private.feature_backup_20261002_mdm_wms`（273 行，匿名和普通认证角色无读取权限）。上线后核对 180 条单据类型均有菜单范围、85 条业务类型均在所属单据类型范围内；多菜单及库存转移写入、非法菜单和默认冲突等路径已在回滚事务中验证。

2026-10-03 修正默认单据类型扩展到其他菜单时的保存冲突：保存前显示会被替换的默认类型并要求确认；保存时数据库按同租户、菜单范围交集取消旧默认标记，再写入新归属。若旧类型同时关联多个菜单，其全部默认标记都会取消，界面会明确提示。原触发器定义已备份在本地忽略目录 `supabase/backups/20261003-mdm-menu-default-guard/rollback.sql`。使用 `SCM20` 与 `WMS_PURCHASE_INBOUND` 验证了覆盖路径，随后恢复两条记录原有的菜单范围和默认状态；验证操作更新了这两条记录的审计时间。最终检查未发现同租户菜单默认项重叠。

### 维护边界

```text
来源应用维护权威主档
  → MDM 通过安全读取契约汇总
  → 识别完整度与来源
  → 用户返回来源应用修正
```

统一目录是只读治理入口，不是第二套业务写入口。不要在 MDM 中复制客户、车辆、员工或设备后形成两套身份，也不要仅按名称或编号自动合并记录。历史单据、事故人员、培训参与人员等发生时快照继续保留历史事实。

## 生产组织与人员

生产部门/产线使用独立的生产树，并引用平台组织身份。生产人员从 HR 的租户内最小字段员工契约选择，保存可用于现场执行的生产身份与工种配置，但不反向修改员工花名册。

部门查看权限和人员档案查看权限彼此独立。没有人员查看权限时，页面不会加载人员表格、表单或人数统计，也不会发起人员查询。

## 工厂日历

工厂日历用于定义生产部门可执行的班次和日期安排：

- 班次支持休息区间、跨午夜和交班重叠时间。
- 轮班模式可以按周期组合多个班次，再批量应用到目标日期。
- 参考模式只允许复制当前租户已有模式，并与直接新增权限分开控制。
- 修改轮班模式会影响引用它的日历；删除模式会清理相应日期，操作前应核对影响范围。
- 页面提供覆盖缺口和提前天数提醒，当前尚未连接微信公众号通知通道。

## 标准作业、工作中心与工艺路线

推荐配置顺序：

```text
作业模板与任务清单
  → 工作中心与主工序位
  → 常驻 / 临时人员安排
  → 主设备与执行规则
  → 产品工艺路线与工序步骤
  → 模板、工作中心和工序绑定
```

作业模板作为一份原子文档保存，任务评分由服务端校验。工作中心可以维护人员、设备、报工、投料、检验、排程和自动化规则，并生成不可变二维码标识。临时人员调整使用明确时间区间，设备不能被多个工作中心重复占用。

这些配置只定义生产基础和未来执行契约。生产订单、派工、机器采集、报工、质检和完工实绩属于 [MES](/modules/mes)，库存移动与完工入库属于 [WMS](/modules/wms)。

## 权限与安全

- 普通用户只能读取当前租户及授权范围内的治理目录和生产基础数据。
- 统一目录只读不代表来源数据公开，敏感字段仍由来源应用的安全投影控制。
- 生产配置的新增、修改、复制、绑定、导入和状态变化需要精确按钮权限及服务端校验。
- RLS、RPC、租户复合外键与内部引用索引共同阻止跨租户访问和删除仍被引用的记录。

## 常见问题

| 问题                       | 检查                                                   |
| -------------------------- | ------------------------------------------------------ |
| 统一目录找不到某类主档     | 来源应用、租户、记录状态、目录类型和读取权限           |
| 主档显示“待完善”           | 详情中的质量项，并返回权威来源应用补齐                 |
| 部门页看不到人员           | 人员查看权限、员工状态、生产人员配置及租户范围         |
| 日历无法引用轮班模式       | 日历查看、参考模式权限、目标部门是否已有模式和日期范围 |
| 工作中心无法绑定人员或设备 | 生产人员启用状态、时间重叠、设备占用和当前租户         |
| MES 无法读取工作中心或工艺 | 配置状态、工艺绑定、跨模块服务契约和 MES 当前实施阶段  |
