# WMS 仓储管理

WMS 面向仓网、库存和入出库执行，目标是围绕仓库、库区、库位、物料、批次/序列号与库存状态，把收货、上架、库内移动、拣选、复核、发运和盘点形成可追踪的仓储闭环。

::: tip 当前实施状态
WMS 已接入库存批次与流水、收料入库、领料申请、出入库、退货、调拨、盘点、调整和序列号追溯。库存过账由数据库受控函数执行。预约、波次拣选、复核与装车交接仍需要独立业务契约。2026-09-30 的业务数据清理后，演示环境可能显示空库存；这不代表功能未接入。
:::

## 目标仓储流程

```text
到货预约
  → 收货与数量交接
  → 质检衔接与上架
  → 库存形成
  → 补货 / 移库 / 盘点
  → 波次 / 拣选 / 复核
  → 发运与装车交接
  → 库存流水、批次和任务追溯
```

## 上线前准备

1. 在 [MDM](/modules/mdm) 明确仓库、场所、存放位置、物料及其权威来源和身份映射。
2. 建立仓库、库区、库位、容器和存储约束，区分可用、待检、冻结、不合格等库存状态。
3. 核对入库、库内、出库、退货和盘点单据的状态机、数量规则与反向操作。
4. 为收货、上架、移库、冻结、解冻、拣选、复核、发运和盘点调整分别配置权限。
5. 用测试租户跑通一次入库、移库、出库和盘点，核对流水、余额、幂等和跨仓权限。

## 公司级库存初始化

“启用库存”与“结束初始化”页面均只展示公司类型的库存组织。“结束初始化”还要求已设置启用日期；部门和事业部不出现在该页面。结束初始化的服务端操作在生成期初余额前再次校验组织类型、启用状态、操作权限和租户范围，直接调用接口也不能为部门结束初始化。历史部门初始化记录保留，不删除组织或库存业务数据。

“启用库存”可在启用单个公司库存组织时将其设为默认；同一租户只能有一个已启用的默认库存组织，批量启用不会同时设为默认。初始库存单新增时优先带出该组织，并仅列出分配给“初始库存单”菜单且已启用的单据类型和业务类型；业务类型同时受所属单据类型约束。业务日期初始为当天，可修改；仓管员可参选；物料明细提供新增、复制、编制、删除和序列号操作。服务端再次验证初始库存单的类型菜单归属、默认组织的租户范围与授权。2026-10-02 变更经私有备份、事务回滚演练及数据核对后应用；当前一个已启用的库存组织被标为默认，未发现无效默认记录，已有初始库存单的类型关联均有效。备份位置见 [MDM](/modules/mdm)。

## 库存模型原则

库存余额是业务流水的汇总结果，不是可以任意编辑的主数据。

- 同一库存身份至少要明确租户、仓库、库位、物料、批次/序列号和库存状态。
- 现存量、占用量、冻结量、在途量和可用量必须定义一致的计算口径。
- 收货、上架、移库、领料、退料、拣选、发运和盘点差异都要形成可追溯流水。
- 重试和外部回调必须使用幂等键，避免重复增加或扣减库存。
- 负库存、跨仓移动、批次失效和状态转换由服务端约束，不能只靠前端提示。

## 与 MDM、MES、TMS 协作

- MDM 提供仓库、场所、存放位置和物料的治理身份；WMS 维护库存状态与仓储作业事实。
- MES 通过受控契约发起领料、退料、物料配送和成品入库，不能直接修改 WMS 余额。
- [SCM](/modules/scm) 的采购收料明细与销售发货通知可分别下推 WMS 收料入库草稿和销售出库；WMS 负责实际过账与库存流水。
- TMS 与 WMS 的来源单据及承运交接回执仍待贯通，不应把 SCM 通知或 WMS 出库直接当成 TMS 发车完成。
- 危废仓库等领域对象在身份关系明确前不能只按名称并入通用仓库或库位。

## 权限与安全

- 普通用户只能读取当前租户及授权仓库范围内的数据。
- 库存查询与业务写入分开授权，跨仓、冻结、盘点调整和反向操作应使用更细权限。
- 页面可见不代表后端授权，RLS、RPC、库存约束、事务和幂等规则是最终边界。
- 尚未接通的波次、复核和装车交接不得用前端模拟写入或直接改表替代。

## 常见问题

| 问题                   | 检查                                         |
| ---------------------- | -------------------------------------------- |
| 只能看到仓储工作台     | 核对库存、入库、出库与盘点页面的菜单授权     |
| 找不到仓库、库位或物料 | MDM 来源、映射、记录状态、租户和读取权限     |
| 可用量与现存量不一致   | 占用、冻结、待检、在途和未完成作业           |
| 作业重试后数量重复     | 幂等键、事务边界、回调去重和原单据状态       |
| MES 完工后没有入库任务 | MES 完工事件、物料批次、目标仓库和跨模块契约 |
| TMS 发运状态不同步     | 复核、装车交接、发运事件、回调和双方状态映射 |
