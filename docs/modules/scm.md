# SCM 供应链管理

SCM 把销售报价、合同、订单、发货通知与采购单据放在同一供应链业务域。入口与操作取决于当前租户的菜单和按钮授权。

## 当前可用范围

| 业务     | 页面与办理内容                                                         |
| -------- | ---------------------------------------------------------------------- |
| 销售报价 | 报价费用定义、报价项分类、销售报价单、项目报价                         |
| 销售管理 | 销售合同、销售订单、发货通知单、发货装车                               |
| 采购管理 | 采购申请、采购合同、采购订单、收料通知、采购入库与退货、委外收料与入库 |

报价、合同、订单和通知单保留来源单据关联与明细计价。金额、来源关系、可发货剩余数量和状态转换由服务端复核；不能仅凭前端显示判断单据可提交。

## 与 WMS 的已接通流程

1. 在 MDM 确认物料、仓库、组织及项目归属；仓库业务范围与库位配置应支持目标作业。
2. 已审核采购订单和已提交收料通知单支持按单据或明细下推采购入库单，直接打开已带入来源信息和剩余数量的新增表单。按本批数量保存、提交和审核，可重复办理分批入库。
3. 已提交的发货通知单可进入 WMS 销售出库。选择仓库后按通知行与剩余数量办理。
4. 库存以 WMS 过账结果为准；SCM 单据状态不能代替库存流水。

采购订单明细展示已送货、已入库、未入库和已退货数量，以及来源单据、源行号，并支持按采购订单模板批量打印。收料通知单提供撤回和按单据、按明细批量删除；删除前检查业务引用。旧的确认收料、下推收料入库及下推资产应付入口已移除。

项目报价可生成销售合同草稿。采购申请到 MES 生产计划的“生成计划”链路尚未接通，页面提示不可执行时不要绕过该状态。TMS 运单与 WMS 出库之间也尚无统一来源单据及交接回执契约，出库完成不等于承运交接完成。

## 权限与异常处理

- 普通用户仅访问本人租户内已授权的单据；跨租户写入由服务端拒绝。
- 新增、编辑、提交、转换来源单据和出入库下推分别按相应业务权限控制。
- 下推失败时保留原单据，先核对状态、剩余数量、仓库范围及服务端反馈，再重试。

独立开发默认使用 `http://localhost:3021/`。源码位于 `modules/art-supabase-scm`，与主仓协作参见[业务模块协作](/development/modules)。
