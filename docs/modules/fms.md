# FMS 财务管理

FMS 提供结算、资金、会计、票据、税务、资产和报表能力，并与 TMS 运单、HR 薪资等业务契约协作。

## 初始化顺序

1. 创建账套并设置会计期间。
2. 维护会计科目、辅助核算、币种汇率和期初余额。
3. 维护资金账户、费用项目、凭证模板和自动入账规则。
4. 配置付款申请、报销、凭证、过账、结账和反向操作权限。
5. 用测试账套完成一轮“业务单据 → 凭证 → 账簿 → 报表 → 结账”。

## 运输结算

客户对账与承运商对账基于运单、费用和业务状态生成。先核对运单范围、计价规则、调整项和税额，再确认对账单。收付款、核销和发票应引用明确的结算对象，避免形成无法追溯的孤立交易。

## 资金管理

- 资金账户维护银行、现金或其他资金载体。
- 资金日记账记录流入流出和余额变化。
- 资金调拨必须同时确认转出、转入账户与执行状态。
- 银行对账通过导入流水、匹配业务记录和差异处理完成。
- 付款申请与费用报销可接入审批流程，审批完成后再执行付款。

## 会计处理

凭证中心承载草稿、审核、过账、作废等状态。自动入账规则用于从业务事件生成凭证草稿；财务人员仍需核对科目、辅助项、借贷平衡、期间和来源单据。

月末结账前至少确认：

- 本期业务单据已处理或明确结转。
- 凭证借贷平衡并完成必要审核/过账。
- 银行对账和关键往来差异已处理。
- 固定资产折旧、薪资、税务和期末调整已完成。
- 报表勾稽关系通过。

## 发票、票据与资产

发票管理、商业票据、固定资产和税务管理各自保留完整生命周期。OCR 只用于辅助录入，发票号码、金额、税额、抬头和重复性必须人工或规则复核。

## 权限与审计

制单、审核、过账、作废、付款、核销、结账和反结账应拆分权限。高风险反向操作必须记录操作人、原因、时间和关联单据，不能通过直接修改状态字段完成。

## 常见问题

| 问题             | 检查                                         |
| ---------------- | -------------------------------------------- |
| 无法生成对账     | 运单状态、费用完整性、结算期间和租户契约     |
| 凭证不平         | 科目方向、税额、舍入、辅助核算和自动入账规则 |
| 无法结账         | 未过账凭证、未处理差异、未完成折旧或期间状态 |
| 银行流水无法匹配 | 金额、日期、对方、摘要、已匹配状态和导入重复 |
| 报表数字异常     | 期间、账套、科目映射、期初余额和过账范围     |
