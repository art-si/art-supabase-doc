# PMIS 设备管理

PMIS 围绕设备点检、巡检、保养和维修组织计划、任务、执行记录与分析。基础设备身份与生产执行使用项目已有的权威数据和权限边界。

## 当前页面

| 领域       | 页面                               |
| ---------- | ---------------------------------- |
| 设备运营   | 工作台、点检看板、各类任务与分析   |
| 点检与巡检 | 计划、任务、记录明细、报表和分析   |
| 预防性维护 | 计划、任务、明细和分析             |
| 保养       | 设置、计划、任务、明细、报表和分析 |
| 维修       | 设置、任务和分析                   |

设备点检与设备巡检沿用既有菜单名称和层级；页面是否出现取决于角色授权。能看到任务不等于有执行或配置权限。

## 推荐办理顺序

1. 核对设备、部门和执行人员身份，确认记录属于当前租户。
2. 维护计划与周期，按授权生成或分派任务。
3. 执行人记录检查、处理结果和必要附件；异常交由维修或业务负责人处理。
4. 在报表与分析页面复核未完成、逾期和异常任务，必要时回到原记录追踪。

计划、执行和状态变化应由对应业务页面及服务端契约完成。不要把分析页的汇总值当成可直接修改的设备记录。

## 与 MES 的边界

MES 的生产执行页面可以关联设备及 PMIS 任务，但制造报工和设备维护保留各自的状态、权限与审计。设备不可用或维护未完成时，先核对 PMIS 记录与生产任务的实际关联，避免只凭设备名称判断。

独立开发默认使用 `http://localhost:3020/`。源码位于 `modules/art-supabase-pmis`，与主仓协作参见[业务模块协作](/development/modules)。
