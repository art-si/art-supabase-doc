# AI 能力使用手册

亿企工场的 AI 能力覆盖智能填单、SQL 辅助、项目分析、调度建议、运输异常、费用审核、利润与回款风险、车辆健康、OCR 和运行质量运营。

## 能力分级

| 级别                      | 普通用户                                      | 平台超级管理员                                                 |
| ------------------------- | --------------------------------------------- | -------------------------------------------------------------- |
| 租户内只读分析            | 可用，需启用且有数据权限                      | 可用                                                           |
| 生成建议或草稿            | 可用，由人工确认                              | 可用                                                           |
| 回填未保存表单            | 可用，用户仍需主动保存                        | 可用                                                           |
| AI 创建本租户主数据       | 持对应业务 `Add` 权限，经服务端租户校验后可用 | 全部租户下默认写入平台租户；可明确指定其他租户，并校验业务权限 |
| 其他业务数据修改          | 不允许                                        | 仅受控模式、显式权限和服务端校验                               |
| Provider/模型/Prompt 配置 | 不允许                                        | 允许并审计                                                     |
| 发布与工作流状态变化      | 不允许                                        | 仅显式权限和服务端边界                                         |

## 智能填单

用户可以粘贴客户聊天、运输委托等文本，或上传订单图片。AI 识别字段、匹配主数据并给出建议，操作人员核对后再回填和保存。

缺少已接入建档的客户、地址或货物主数据时，普通用户持对应业务 `Add` 权限可创建本租户记录。平台超级管理员在“全部租户”范围下建档默认归入自己的平台租户；如需归入其他租户，应先明确选定目标。当前线上智能开单建档 RPC 仍要求先选定租户，待服务端更新后该默认规则才会在智能开单中生效。

![AI 智能填单](/screenshots/ai-order.png)

核对重点：客户、地址、联系人、货物、数量/重量/体积、时间、计价规则与承运要求。低置信度或主数据不一致时，不要直接保存。

## 业务分析

调度、异常、费用、利润、回款和车辆健康建议都属于决策辅助。使用者应核对数据时间、样本范围、缺失字段和业务规则，不把模型输出当成已执行指令。

## 反馈与审计

每次运行可以记录能力、模型、耗时、Token、结果状态和用户反馈。AI 运行中心用于观察成功率、延迟、失败原因和质量趋势。

![AI 运行中心](/screenshots/ai-operations.png)

提交反馈时说明“哪里不对、正确结果是什么、是否影响业务”，不要粘贴无关个人信息或外部密钥。

## 安全注意事项

- 不在提示词中输入密码、secret key、`service_role` 或未授权个人信息。
- AI 上下文必须继续遵守租户、菜单、字段和数据权限。
- AI 生成 SQL 在执行前检查表、字段、过滤范围和只读性质。
- 受控写入必须可预览、可确认、可审计，并在服务端再次鉴权。
- Provider 原始错误不直接展示给普通用户，界面应给出可操作的中文说明。
