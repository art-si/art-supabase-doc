# 数据中心

数据中心提供字典、附件、SQL 工作台与 Supabase AI 助手等平台能力。这里同时包含高价值数据和高风险工具，应严格按职责授权。

## 数据字典

数据字典统一维护状态、类型、分类、是否值等可枚举业务含义。建议：

- 稳定的业务值使用代码，显示名称可以调整。
- 不要删除已经被业务记录使用的值；优先停用。
- 颜色和展示类型只表达状态，不替代文字。
- 共享是/否值使用公共布尔字典，避免各模块重复定义。

## 附件管理

附件记录与 Supabase Storage 配合使用。上传、预览、下载、替换和删除都要校验租户、记录归属和业务权限。替换文件属于 upsert，需要 Storage 策略同时允许 `INSERT`、`SELECT` 和 `UPDATE`。

## SQL 工作台

SQL 工作台提供 PostgreSQL 编辑、格式化、补全、错误定位和结果查看。使用原则：

- 普通用户只获得租户范围内、安全的只读查询。
- 写 SQL、DDL、跨租户查询或特权函数不能仅靠前端关键字拦截。
- 执行边界应由服务端解析、允许列表、权限和数据库角色共同约束。
- 结果中包含敏感字段时，仍要遵守字段权限和最小披露原则。

## Supabase AI 助手

项目助手可浏览 Database、视图、函数、触发器、RLS 与 Edge Functions，并基于实时元数据给出只读分析和治理建议。它不应直接执行 SQL 或修改项目。

![Supabase AI 项目助手](/screenshots/supabase-assistant.png)

## 使用前检查

1. 当前账号是否有目标数据域的读取权限。
2. 查询是否包含不必要的个人、财务或跨租户字段。
3. 导出或复制结果是否符合组织的数据处理规范。
4. AI 建议是否经过人工核对，尤其是安全、迁移和性能建议。
