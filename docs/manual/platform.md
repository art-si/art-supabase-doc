# 工作台与通用操作

登录后，平台根据当前用户的角色菜单动态装载可访问应用。左侧导航用于业务域切换，顶部区域提供全局搜索、应用切换、语言、通知、主题和个人入口。

## 工作台

工作台聚合当前最需要处理的信息：开单、待配载、运输中、风险任务、业务趋势与快捷入口。不同角色看到的数据和入口可能不同，这是租户、角色和菜单授权共同作用的结果。

推荐日常顺序：

1. 先查看风险、异常和待审批数量。
2. 进入主任务入口处理工作。
3. 在列表中使用筛选缩小范围，避免全量浏览。
4. 处理完成后返回工作台确认指标与待办是否更新。

## 列表页面

大多数业务列表包含搜索区、工具栏、数据表格和分页：

- 搜索条件用于缩小数据范围；“重置”恢复默认条件。
- 列设置用于调整可见列、顺序或密度。
- 新增、导入、导出等操作只在拥有对应按钮权限时出现。
- 行内“详情、编辑、更多”作用于当前记录；状态不允许时，操作可能被禁用。
- 批量操作只对已选择记录生效，提交前核对数量和范围。

## 表单、弹窗与抽屉

- 带星号的字段为必填项；校验错误会出现在字段附近。
- “保存更改”只保存当前表单，“提交审核”会进入工作流，两者含义不同。
- 保存过程中不要重复点击；失败后已输入内容通常会保留。
- 关闭未保存表单前，留意页面或弹窗的离开提示。
- 详情页用只读信息区呈现数据，不要把灰色禁用输入框误认为可编辑字段。

## 搜索与导航

顶部全局搜索用于快速定位已授权页面。浏览器刷新后，系统会根据后端菜单重新恢复路由；如果页面突然消失，应先确认角色和菜单，而不是把页面写入静态路由。

## 主题与显示

系统支持亮色/深色主题和界面设置。主题只改变视觉，不改变业务权限。窄屏下侧栏会折叠；表格仍可能需要在表格区域内横向滚动，但页面本身不应产生无意义的横向滚动。

## 常见状态

| 状态     | 含义                 | 建议操作                             |
| -------- | -------------------- | ------------------------------------ |
| 加载中   | 正在请求或计算       | 等待完成，不重复提交                 |
| 暂无数据 | 当前条件下没有记录   | 调整筛选或使用允许的新增入口         |
| 无权限   | 角色或服务端拒绝     | 联系租户管理员核对精确页面/按钮权限  |
| 请求失败 | 网络、会话或服务异常 | 按提示重试；持续失败时记录时间与页面 |
| 已禁用   | 当前业务状态不允许   | 查看状态说明或先完成前置步骤         |
