# Yiqi Workshop Documentation

The official VitePress documentation site for [Yiqi Workshop](https://gitee.com/art-si/art-supabase-pro). It covers the shared platform, SCM, MDM, MES, WMS, TMS, VMS, PMIS, FMS, HR, SMIS, the driver app, governed AI, setup, development, Supabase security, deployment, and operations.

[Gitee](https://gitee.com/art-si/art-supabase-doc) · [GitHub](https://github.com/art-si/art-supabase-doc) · [Live Documentation](https://art-si.github.io/art-supabase-doc/) · [简体中文](./README.md)

```powershell
pnpm install
pnpm docs:dev
```

Requirements: Node.js 22 or later and pnpm 11.9 or later.

Build and preview with `pnpm docs:build` and `pnpm docs:preview`. The default public base path is `/art-supabase-doc/`; set `DOCS_BASE=/` when deploying at a domain root.

The Chinese documentation under `docs/` covers installation, operations, business modules, development, Supabase security, deployment, and troubleshooting.
