# Art Supabase Pro Documentation

The official documentation site for [Art Supabase Pro](https://gitee.com/wangyanghub/art-supabase-pro), built with VitePress.

```powershell
pnpm install
pnpm docs:dev
```

Build and preview with `pnpm docs:build` and `pnpm docs:preview`. The default public base path is `/art-supabase-doc/`; set `DOCS_BASE=/` when deploying at a domain root.

The Chinese documentation under `docs/` covers installation, operations, business modules, development, Supabase security, deployment, and troubleshooting.
